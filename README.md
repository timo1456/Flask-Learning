# Flask Learning

A focused interactive Flask learning website: direct syntax, why it works, short challenges, quizzes, and progress tracking.

Run locally:

    python -m venv .venv
    .venv\\Scripts\\activate
    pip install -r requirements.txt
    flask --app app run --debug

Open http://127.0.0.1:5000.

The curriculum covers Flask routing, requests, Jinja, forms, sessions, authentication, SQL, SQLAlchemy, CRUD, relationships, uploads, blueprints, factories, APIs, fetch, errors, security, configuration, migrations, testing and deployment.
